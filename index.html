《TOKEN》隐私政策

更新日期：2026年8月31日 生效日期：2026年8月31日
本版本要点：《TOKEN》当前版本无需注册账号，不进行实名认证，不提供支付功能，未接入真实广告 SDK，也未正式接入 TapTap 登录或排行榜 SDK。游戏进度与设置主要保存在您的设备本地；震动仅用于提供游戏反馈，不用于收集个人信息。

欢迎您使用《TOKEN》（以下简称“本游戏”）。本游戏由一昂工作室运营。我们重视您的隐私和个人信息安全，并遵循合法、正当、必要和诚信原则处理与本游戏有关的信息。

请您在使用本游戏前阅读并了解本政策。本政策用于说明当前公开版本的实际信息处理情况；如后续版本的功能或信息处理方式发生变化，我们将及时更新本政策。

01适用范围

本政策适用于一昂工作室运营的《TOKEN》移动端游戏。第三方平台自身提供的下载、安装、更新等服务，由相应平台按照其规则处理；本政策仅说明本游戏自身的处理行为。

02我们如何处理信息

2.1 当前版本不收集的个人信息

本游戏当前版本不设置自有账号体系，不要求您提供手机号、密码、姓名、身份证件信息或其他实名认证信息，也不以运营者服务器为您建立个人账户档案。

2.2 本地游戏数据

为保存您的游戏进度和使用偏好，本游戏会在您的设备本地生成并保存必要的游戏数据，例如电力、金钱、算力、Token 等游戏内资源数据，建筑、工具及科技的购买与解锁状态，开创、颠覆及成就记录，自动化设置，音乐、音效、震动等设置项，教程状态以及计算离线收益所需的本地时间记录。

上述数据主要保存在您的设备本地，用于恢复游戏进度和实现游戏功能。当前版本不会由一昂工作室通过自有服务器主动上传上述游戏存档。

您可以通过游戏提供的清档功能（如有）、Android 系统的“清除应用数据”功能或卸载本游戏删除相关本地数据。删除后，游戏进度可能无法恢复。

2.3 震动反馈

本游戏会在特定游戏操作或事件发生时使用设备的震动功能，以提供触觉反馈。调用震动功能不会读取、收集或上传您的个人信息。您可以在《TOKEN》的“设置”页面关闭震动反馈；部分设备也可能提供相应的系统级控制选项。

2.4 联系我们时产生的信息

如果您主动通过电子邮箱、电话等方式联系我们，我们可能会处理您主动提供的电子邮箱地址、电话号码、问题描述、截图以及您选择提供的其他信息。

我们仅将上述信息用于处理您的咨询、意见、投诉、故障反馈或其他请求，并在实现相关处理目的所必要的最短期限内保存；法律法规另有规定的除外。

请您不要在反馈过程中主动提交身份证号码、银行卡号、账号密码等与解决问题无关的敏感个人信息。

03设备权限说明

当前版本核心游戏功能不需要访问您的麦克风、摄像头、通讯录、短信、通话记录、精确地理位置或照片内容。游戏会使用设备震动功能提供触觉反馈。若后续版本新增需要调用其他设备权限的功能，我们将在实际使用前说明目的，并依法履行相应程序。

04账号、支付、广告与第三方 SDK

根据当前版本的实际功能状态，本游戏：

  • 无自有账号注册或登录
  • 无实名认证
  • 无支付或充值功能
  • 无真实广告 SDK
  • 无正式 TapTap 登录 SDK
  • 无正式 TapTap 排行榜 SDK

因此，本游戏不会通过上述尚未接入的功能或 SDK 收集、使用或向第三方提供您的个人信息。如果未来版本正式加入登录、排行榜、广告、支付、云存档、统计分析或其他第三方 SDK，我们会在相关版本发布前更新本政策，明确说明处理目的、方式、信息种类及第三方情况，并依法履行必要的告知与同意义务。

05信息的共享、转让与公开披露

当前版本游戏本体不会为了广告投放、用户画像、营销等目的向第三方共享您的个人信息，也不会出售您的个人信息。

如果您主动通过电子邮箱、电话等方式联系我们，相关通信服务本身可能由电子邮箱服务商、电信运营商等按照其自身规则提供。

此外，在取得您的明确同意，或者根据法律法规、有权机关依法提出的要求等法律允许的情况下，我们可能在必要范围内提供相关信息。

如未来新增第三方 SDK 或其他导致个人信息共享的功能，我们将在上线前更新本政策，并依法履行相应告知和同意程序。

06信息存储与安全

游戏进度和基础设置主要保存在您的设备本地，保存期限通常与本游戏在设备上的存续期间一致。清除应用数据、卸载游戏、恢复出厂设置或更换设备，均可能导致本地数据被删除或无法恢复。

我们会在当前业务范围内采取合理措施保护本游戏及相关数据安全。请您同时妥善保管设备，并及时安装可信的系统安全更新。

07您的权利

当前版本没有自有账号及运营者服务器个人资料，因此不提供账号资料查询、更正或注销入口。对于保存在设备本地的游戏数据，您可以通过清除应用数据或卸载本游戏进行删除。

如果您对本游戏的信息处理情况有疑问，或希望依法行使与个人信息有关的权利，可以通过本政策末尾的联系方式与我们联系。我们会在核实情况后依法处理。

08未成年人保护

我们重视未成年人的个人信息保护。未成年人应在父母或其他监护人的指导下阅读本政策并使用本游戏；不满十四周岁的未成年人应在监护人同意和指导下使用本游戏。

当前版本不要求用户提交年龄、身份或实名认证信息，也不主动收集未成年人的个人信息。如果您认为未成年人的个人信息被不当处理，请通过本政策末尾的联系方式联系我们。

09本政策的更新

我们可能根据游戏功能、信息处理方式或法律法规的变化修订本政策。涉及处理目的、方式、信息种类、第三方 SDK 等重要内容变化时，我们会在新版本发布前更新政策，并通过适当方式提示您阅读。

未经依法告知并在必要时取得您的同意，我们不会通过政策更新擅自扩大个人信息处理范围。
