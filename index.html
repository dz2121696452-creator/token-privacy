Privacy Policy

《TOKEN》隐私政策

更新日期：2026年9月6日 生效日期：2026年9月6日 适用版本：TOKEN 0.1.5
本版本要点：游戏存档主要保存在设备本地。激励视频广告属于可选功能；只有在您同意本政策后，TapADN / Dirichlet 广告 SDK 才会初始化。拒绝不会影响核心游戏功能。

01引言

欢迎您使用《TOKEN》（以下简称“本游戏”）。本游戏由一昂工作室运营。我们重视您的隐私和个人信息安全，并遵循合法、正当、必要和诚信原则处理与本游戏有关的信息。

请您在使用本游戏前阅读并了解本政策。本政策说明 TOKEN 0.1.5 当前实际的信息处理方式以及您可以作出的选择。

02我们处理的信息

本游戏当前不设置自有账号体系，不要求您提供手机号、密码、姓名、身份证件信息或实名认证信息，也不提供支付或充值功能。

为实现游戏功能，本游戏会在您的设备本地处理游戏进度与设置。只有在您同意本政策并使用可选激励广告功能时，TapADN / Dirichlet 广告 SDK 才会初始化，并可能按照本政策第 6 节处理广告服务所需的信息。

如果您主动通过电子邮箱、电话等方式联系我们，我们可能处理您主动提供的联系方式、问题描述、截图以及您选择提供的其他信息，仅用于回应咨询、意见、投诉或故障反馈。请勿提交与解决问题无关的敏感个人信息。

03本地游戏数据与存档

为保存您的游戏进度和使用偏好，本游戏会在设备本地保存必要数据，包括游戏内资源，建筑、工具与科技的购买和解锁状态，开创、颠覆与成就记录，自动化设置，音乐、音效、震动设置，教程状态，隐私选择，以及计算离线收益所需的本地记录。

上述游戏存档主要保存在您的设备本地，用于恢复进度和实现游戏功能。当前版本不会由一昂工作室通过自有服务器主动上传该游戏存档。清除应用数据或卸载本游戏可能删除这些本地数据，且删除后可能无法恢复。

04网络功能

核心游戏功能可在不启用广告服务的情况下使用。网络连接主要用于您同意后进行广告请求、加载和展示可选激励视频，以及完成广告服务所需的网络通信。

第三方下载、安装、更新或应用商店服务由相应平台按照其规则处理。

05广告与激励视频

本游戏集成 TapADN / Dirichlet 广告 SDK，当前仅提供可选的激励视频广告，不使用强制广告、开屏广告、插屏广告、横幅广告或信息流广告。您可以选择不观看广告，核心游戏功能仍可正常使用。

激励视频对应三类可选奖励：

  1. 在限定时间内提升发电效率；
  2. 立即获得一定时长对应的自动发电产出；
  3. 将一次待领取的离线收益加倍。

完整观看并收到广告 SDK 的有效奖励回调后，游戏才发放相应奖励。提前关闭广告不会发放完整激励。游戏使用广告会话校验和已完成记录，防止同一奖励被重复发放。

首次启动时，本游戏会显示自己的隐私同意页面。您可以选择“同意并进入游戏”或“不同意”：

  • 同意后，游戏才允许初始化 TapADN / Dirichlet 广告 SDK，并提供广告相关功能；
  • 不同意时，TapADN / Dirichlet 广告 SDK 不初始化、不预加载广告，也不发起广告请求；广告功能不可用或不会启动，但核心游戏仍可正常使用。

本游戏当前默认限制个性化广告，不主动开启个性化广告推荐。

根据 TapADN 当前官方隐私政策，SDK 基本功能可能处理以下信息：

  • 设备信息：设备品牌、型号、操作系统版本、屏幕密度、屏幕分辨率、设备语言、设备时区、CPU 信息、可用存储空间，以及 Android 设备标识符 OAID；
  • 网络信息：Wi-Fi 状态、网络信号强度、IP 地址；
  • 应用信息：应用包名、运行中的进程信息、版本号、应用前后台状态；
  • 广告交互信息：广告展示、点击和转化数据；
  • 性能信息：崩溃数据和性能数据。

TapADN 官方说明还列有由开发者选择启用的可选信息与权限。TOKEN 0.1.5 通过 SDK 合规控制关闭位置、电话状态、IMEI、Android ID、软件列表和外部存储访问，不申请相应可选权限。具体处理情况可能因 SDK 版本、设备环境和官方政策更新而有所不同，请同时查阅上述官方政策。

TapADN 可能依照其隐私政策与广告合作方共享提供广告服务所必需的去标识化或匿名化设备、网络、广告交互及统计信息。相关信息的存储、共享、保存期限和安全措施由 TapADN 按其官方政策处理。

07权限说明

TOKEN 0.1.5 的 Android Release 最终权限包括：

  • android.permission.INTERNET：用于广告请求、素材加载及必要的网络通信；
  • android.permission.ACCESS_NETWORK_STATE：用于判断网络状态并保障广告服务连接；
  • android.permission.VIBRATE：用于您可在游戏设置中关闭的触觉反馈；
  • com.asus.msa.SupplementaryDID.ACCESS、freemme.permission.msa：由广告 SDK 使用的设备标识兼容能力。

当前 Release 不包含 android.permission.REQUEST_INSTALL_PACKAGES 和 android.permission.QUERY_ALL_PACKAGES，也不申请定位、电话状态、读写外部存储、通讯录、相机、麦克风、短信或通话记录权限。

Manifest 中出现某项权限并不表示一昂工作室会主动收集该权限可能涉及的全部数据；实际处理目的和范围以本政策、当前应用配置及第三方 SDK 官方说明为准。

08信息存储与安全

游戏进度和基础设置主要保存在您的设备本地，保存期限通常与本游戏在设备上的存续期间一致。清除应用数据、卸载游戏、恢复出厂设置或更换设备，均可能导致本地数据被删除或无法恢复。

TapADN 对广告服务相关信息的存储地点、期限和安全措施以其官方隐私政策为准。我们会在当前业务范围内采取合理措施保护本游戏及相关数据安全；但任何技术措施都无法保证绝对安全，请您同时妥善保管设备。

09用户选择与权利

您可以拒绝广告相关隐私处理，并继续使用核心游戏。拒绝后，广告 SDK 不初始化，广告功能不可用或不会启动。

对于设备本地的游戏数据，您可以通过 Android 系统的“清除应用数据”功能或卸载本游戏进行删除。对于您主动联系我们时提供的信息，或涉及 TapADN 的访问、更正、删除、撤回同意等请求，可通过本政策末尾的联系方式联系我们；我们会在核实情况后依法处理或协助您按照 SDK 提供方的流程处理。

10未成年人相关说明

我们重视未成年人的个人信息保护。未成年人应在父母或其他监护人的指导下阅读本政策并使用本游戏；不满十四周岁的未成年人应在监护人同意和指导下使用本游戏。

本游戏当前不要求用户提交年龄、身份或实名认证信息。如果您认为未成年人的个人信息被不当处理，请通过本政策末尾的联系方式联系我们。

11隐私政策更新

我们可能根据游戏功能、信息处理方式、第三方 SDK 或法律法规的变化修订本政策。涉及处理目的、方式、信息种类或第三方 SDK 等重要内容变化时，我们会在相应版本发布前更新政策，并在需要时再次请求用户确认。未确认新政策版本前，不初始化对应广告服务。
