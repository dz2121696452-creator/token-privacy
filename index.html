《TOKEN》隐私政策

更新日期：2026年10月8日 生效日期：2026年10月8日 适用版本：TOKEN 0.2.0

01引言

欢迎您使用《TOKEN》（以下简称“本游戏”）。本游戏由一昂工作室运营。我们重视您的隐私和个人信息安全，并遵循合法、正当、必要和诚信原则处理与本游戏有关的信息。

请您在使用本游戏前阅读并了解本政策。本政策说明 TOKEN 0.2.0 当前实际的信息处理方式、第三方 SDK 接入情况以及您可以作出的选择。

02我们处理的信息

本游戏不设置一昂工作室自建账号体系，不要求您向一昂工作室提交手机号、密码、身份证件或支付信息。游戏进度、设置和大部分玩法数据主要保存在设备本地。

当您主动使用 TapTap 登录、排行榜或礼包等联网功能时，游戏会按照所选功能与 TapTap 服务交互，并处理实现登录授权、榜单读取/提交、礼包核销所必需的账号标识、游戏成绩、礼包码及相关网络请求信息。

在您知情并同意适用的隐私政策、且主动选择使用激励视频功能后，TosinSDK 及实际启用的广告合作方可能处理广告展示、个性化推荐、监测归因、效果统计、反作弊和服务稳定性所必需的信息。未取得相应同意前，不应初始化广告 SDK 或开展相应信息处理。广告是否实际提供取决于应用版本及服务状态。

如果您主动通过电子邮箱、电话等方式联系我们，我们可能处理您主动提供的联系方式、问题描述、截图以及您选择提供的其他信息，仅用于回应咨询、意见、投诉或故障反馈。请勿提交与解决问题无关的敏感个人信息。

03本地游戏数据与存档

为保存您的游戏进度和使用偏好，本游戏会在设备本地保存必要数据，包括游戏内资源，建筑、工具与科技的购买和解锁状态，开创、颠覆、实相、进化与成就记录，自动化设置，背景与主题选择，音乐、音效、震动设置，教程状态，隐私选择，以及计算离线收益所需的本地记录。

上述本地游戏存档不会由一昂工作室通过自有云存档服务器主动上传。清除应用数据或卸载本游戏可能删除这些本地数据，且删除后可能无法恢复。

TapTap 账号、排行榜成绩及礼包核销属于独立的在线服务数据，不等同于本地完整游戏存档。

04网络功能

本游戏的主要单机玩法可在不使用广告的情况下运行。联网功能主要包括：

  • TapTap 登录及登录状态恢复；
  • 读取和提交 TapTap 排行榜数据；
  • 通过 TapTap 官方礼包接口核验和兑换礼包码；
  • 在广告功能完成生产配置并可用时，请求和展示用户主动选择的激励视频广告；
  • 完成上述服务所需的 HTTPS 网络通信。

第三方下载、安装、更新、应用商店及账号服务由相应平台按照其规则处理。

06广告与激励视频

本游戏集成 TosinSDK 作为广告聚合能力，当前设计仅用于用户主动选择的激励视频广告。是否实际展示广告取决于当前版本的广告生产配置和可用状态；广告不可用不会阻止核心游戏功能运行。

本游戏不会以开屏广告、强制插屏广告或横幅广告作为核心玩法的必要条件。只有在有效的奖励回调被确认后，游戏才会发放相应激励，提前关闭或广告失败不会获得完整奖励。

在您明确同意相关个人信息处理并主动请求激励视频时，实际启用的广告服务可能根据设备与网络信息、设备标识、广告展示和交互记录等进行个性化广告推荐及自动化投放优化；具体处理范围取决于已集成的 SDK、广告渠道及其隐私政策。您有权拒绝个性化营销，亦有权撤回基于同意的授权；拒绝广告相关处理不会妨碍不依赖广告的核心游戏内容。对涉及个人信息处理方式的重要变化，本游戏应在启用前重新征得相应同意。

根据 TosinSDK 官方隐私政策，其在提供服务时可能处理的类别包括：

  • 网络信息，例如 IP 地址、运营商信息、Wi-Fi 状态、网络信号强度及网络类型；可选信息可能涉及 Wi-Fi SSID、BSSID 或设备 MAC 地址；
  • 设备信息，例如制造商、品牌、型号、操作系统版本、屏幕参数、时区、语言、CPU、SIM 卡信息及可用存储空间；Android 设备标识（如 OAID、Android ID），以及经实际配置允许的其他可选设备标识；
  • 应用基础信息，例如宿主应用包名、版本号、进程与运行状态；广告合作方在实际配置允许时可能处理应用安装信息；
  • 传感器信息，例如 Android 加速度、陀螺仪及其他运动传感器信息，用于广告互动、投放或反作弊；
  • 广告交互信息，例如展示、点击、关闭、转化等广告数据；
  • 性能与安全信息，例如崩溃、性能和反作弊相关数据；
  • 供应商政策中列明的其他必要或可选信息，实际范围受 TOKEN 当前 SDK 配置及所启用广告渠道限制。

以上为 TosinSDK 官方政策披露的可能信息范围，不代表 TOKEN 当前实际读取全部信息。游戏将根据 Android 版本、已取得的授权及广告渠道实际依赖，使用 SDK 提供的隐私控制能力限制非必要信息访问；是否使用定位、电话标识、Wi-Fi 详细信息、应用列表及设备标识等，应以最终安装包和运行时配置为准。具体信息处理规则请同时参阅 TosinSDK 官方隐私政策。

为区分安装实例及核对广告奖励请求，本游戏在获得适用的隐私同意后可能生成并保存随机安装标识，用于广告会话、奖励请求关联及防重复发奖，不将其作为您的实名身份信息。

TosinSDK 属于广告聚合 SDK。只有开发者实际接入并启用的广告渠道才应成为 TOKEN 的运行时广告提供方；供应商 SDK 文档中列出的其他可选广告渠道不表示 TOKEN 当前已经接入这些渠道。

08权限说明

TOKEN 0.2.0 当前 Android Release 的最终权限包括：

  • android.permission.INTERNET：用于 TapTap 登录、排行榜、礼包以及可选广告服务的网络通信；
  • android.permission.ACCESS_NETWORK_STATE：用于判断网络连接状态；
  • android.permission.VIBRATE：用于游戏内可关闭的触觉反馈；
  • com.yang.token.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION：应用内部动态广播接收器的隔离保护权限，不属于需要用户授权的敏感系统权限。

当前 Release 不申请定位、电话状态、外部存储、通讯录、相机、麦克风、短信、通话记录、全部应用列表或安装未知应用等敏感权限。

权限清单用于说明 Android 安装包中声明的能力；第三方 SDK 具体处理的信息还会受到其自身 API、应用配置和设备环境影响。

09第三方共享与委托处理

为实现您主动使用的联网功能，本游戏会向对应服务提供方发送提供该功能所必需的信息：

  • TapTap：用于登录授权、排行榜、礼包等平台服务；
  • TosinSDK 及实际启用的广告服务提供方：用于可选激励视频广告、广告统计、归因、反作弊与稳定性。

我们不会向广告商出售您的聊天内容或本地完整游戏存档。第三方服务提供方如何存储、共享、保存和保护其处理的信息，以其公开隐私政策及适用法律法规为准。

10信息存储与安全

游戏进度和基础设置主要保存在您的设备本地，保存期限通常与本游戏在设备上的存续期间一致。清除应用数据、卸载游戏、恢复出厂设置或更换设备，均可能导致本地数据被删除或无法恢复。

TapTap 与 TosinSDK 对其服务相关信息的存储地点、期限和安全措施以各自官方隐私政策为准。我们会在当前业务范围内采取合理措施保护本游戏及相关数据安全，但任何技术措施都无法保证绝对安全。

11用户选择与权利

您可以拒绝使用可选激励视频广告及其相关个人信息处理，继续使用不依赖广告的游戏内容。对经同意开展的个性化广告推荐，您享有拒绝或退出自动化推荐的权利；对基于同意的个人信息处理，您可以撤回同意。可通过本政策末尾联系方式提出相关请求，我们将依法核实和处理。

对于设备本地的游戏数据，您可以使用游戏提供的重置功能或 Android 系统的清除应用数据/卸载功能进行删除。对于 TapTap 或 TosinSDK 处理的信息，您可以依据对应服务提供方的隐私政策行使查阅、更正、删除、撤回同意等权利，也可以通过本政策末尾的联系方式联系我们协助处理。

如果您认为未成年人的个人信息被不当处理，请通过本政策末尾的联系方式联系我们。
